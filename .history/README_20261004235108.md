# ActionFi × SWEEP Case Study

An interactive Web3 landing page showcasing the 7-day protocol activation campaign between **ActionFi** and **SWEEP**.

The campaign demonstrated how outcome-based incentives outperform vanity marketing metrics, converting top-of-funnel discovery into verified, Sybil-resistant on-chain users.

---

## 1. Key Metrics

- **17,000+** New Users Initiated
- **9,500+** KYC Completions Cleared
- **55.8% (~56%)** Conversion Rate (Signup to Verified Identity)
- **7 Days** Total Campaign Duration

---

## 2. Core Narrative

Most Web3 campaigns pay upfront for passive social attention (likes, retweets, impressions). The ActionFi × SWEEP framework deployed milestone-based smart escrow logic:

1. **Discover:** User enters the acquisition pipeline.
2. **Complete:** User performs the target product actions.
3. **Verify:** Sybil-resistant KYC gate validates authentic identity.
4. **Reward:** Settlement unlocks strictly upon verified completion.

---

## 3. Tech Stack

- **Framework:** React + Vite
- **Styling:** Modular CSS with Glassmorphism, CSS Variables, and responsive grids
- **Data Visualization:** Recharts
- **UI Components:** Custom reactive cursor, interactive folder component, animated stat counters
