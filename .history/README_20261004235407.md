# ActionFi × SWEEP Case Study

An interactive Web3 landing page showcasing the 7-day protocol activation campaign between ActionFi and SWEEP.

## Key Metrics
- **17,000+** New Users Initiated
- **9,500+** KYC Completions Cleared
- **55.8% (~56%)** Conversion Rate (Signup to Verified Identity)
- **7 Days** Total Campaign Duration

## Pipeline Flow
1. **Discover:** User enters the acquisition pipeline.
2. **Complete:** User performs the target product actions.
3. **Verify:** Sybil-resistant KYC gate validates authentic identity.
4. **Reward:** Settlement unlocks strictly upon verified completion.

## Tech Stack
- React + Vite
- CSS Modules & Variables
- Recharts
- Custom UI components (Counter, Folder, Interactive Cursor)
